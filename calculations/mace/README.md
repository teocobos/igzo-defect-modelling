# MACE

Machine-learning interatomic potential development for IGZO.

## Planned Workflow

1. Generate diverse DFT configurations.
2. Curate training/validation/test datasets.
3. Train MACE.
4. Validate energy and force errors.
5. Test structural stability.
6. Assess extrapolation.
7. Use validated models for larger-scale sampling.

No model should be used for scientific conclusions before independent validation.
