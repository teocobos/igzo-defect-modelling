# IP and Publication Policy

This project is being developed within the R&D activities of Nanosystems Advisory.

## Public Repository

Only material suitable for public release should be committed to this repository.

This may include:

- General methodology.
- Open-source analysis code.
- Reproducible workflows.
- Publicly available structures.
- Published literature references.
- Non-confidential results.

## Potentially Proprietary Material

Do not commit material that may contain commercially sensitive or patentable information before appropriate review.

Examples include:

- Proprietary algorithms.
- Unpublished optimisation strategies.
- Confidential datasets.
- Commercially sensitive results.
- Unpublished inventions.
- Proprietary trained models.

## Publication

Potential publications should be discussed with relevant collaborators and Nanosystems Advisory before public disclosure where intellectual-property considerations apply.

## Repository Status

The repository should clearly distinguish between:

1. Open research infrastructure.
2. Preliminary scientific work.
3. Published results.
4. Potentially proprietary R&D.
